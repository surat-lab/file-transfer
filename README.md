# Codex backup

Backup created 2026-10-31.

Contents of `codex-backup-2026-10-31.zip`:
- `workspace-markdown/`: Markdown files from the Codex workspace.
- `installed-skills/`: the local Codex skills bundle.
- `plugin-skill-definitions/`: installed plugin `SKILL.md` definitions.

To restore on another computer:
1. Clone this repository.
2. Extract the ZIP.
3. Copy `installed-skills/` into the Codex skills directory on that computer.
4. Keep the workspace Markdown wherever you prefer, or copy it into your Codex workspace.

This archive intentionally contains no machine caches, credentials, or temporary build output.
